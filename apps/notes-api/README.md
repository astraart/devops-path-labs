# notes-api

Учебный сервис заметок на Go для проекта 2 «Сервис в контейнере с пайплайном». Только стандартная библиотека Go, без внешних зависимостей.

## API

| Запрос | Ответ |
|---|---|
| `GET /healthz` | `ok` — сервис жив |
| `GET /version` | `{"version": "…", "commit": "…"}` — подставляются при сборке |
| `GET /notes` | список заметок |
| `POST /notes` с `{"text": "…"}` | `201` и созданная заметка; пустой или длиннее 1000 символов текст — `400` |
| `GET /notes/{id}`, `DELETE /notes/{id}` | заметка или `204`; нет такой — `404` |

```bash
curl -s -X POST -d '{"text": "купить молоко"}' http://localhost:8080/notes
```

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8080` | порт HTTP |
| `DATA_DIR` | пусто | каталог для `notes.json`; пусто — заметки только в памяти |

Версия и коммит задаются при сборке: `go build -ldflags "-X main.version=1.2.0 -X main.commit=abc123"`.

Флаг `-healthcheck` запрашивает `/healthz` у запущенного сервиса и завершается с кодом 0 или 1 — для `HEALTHCHECK` в образе без оболочки и curl.

По `SIGTERM` (его присылают `docker stop` и Kubernetes) сервис дожидается текущих запросов и завершается.
