# notes-api

Учебный сервис заметок на Go для проектов 2 «Сервис в контейнере с пайплайном» и 3 «Инфраструктура из трёх машин». Одна внешняя зависимость — драйвер PostgreSQL [pgx](https://github.com/jackc/pgx).

## API

| Запрос | Ответ |
|---|---|
| `GET /healthz` | `ok` — процесс жив (не зависит от базы) |
| `GET /readyz` | `ready` — хранилище отвечает; база недоступна — `503` |
| `GET /version` | `{"version": "…", "commit": "…"}` — подставляются при сборке |
| `GET /notes` | список заметок |
| `POST /notes` с `{"text": "…"}` | `201` и созданная заметка; пустой или длиннее 1000 символов текст — `400` |
| `GET /notes/{id}`, `DELETE /notes/{id}` | заметка или `204`; нет такой — `404` |

```bash
curl -s -X POST -d '{"text": "купить молоко"}' http://localhost:8080/notes
```

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8080` | порт HTTP |
| `DATABASE_URL` | пусто | строка подключения к PostgreSQL, например `postgres://notes:ПАРОЛЬ@10.0.0.3:5432/notes?sslmode=disable`; если задана, заметки хранятся в базе (таблица создаётся сама) |
| `DATA_DIR` | пусто | каталог для `notes.json`, когда базы нет; пусто — заметки только в памяти |

Версия и коммит задаются при сборке: `go build -ldflags "-X main.version=1.2.0 -X main.commit=abc123"`.

Флаг `-healthcheck` запрашивает `/healthz` у запущенного сервиса и завершается с кодом 0 или 1 — для `HEALTHCHECK` в образе без оболочки и curl.

По `SIGTERM` (его присылают `docker stop` и Kubernetes) сервис дожидается текущих запросов и завершается.

Если базы нет при запуске, сервис завершается с ошибкой — его перезапустит systemd или Docker. Пароль из `DATABASE_URL` в журнал не пишется.

## Тесты без установленного Go

```bash
docker run --rm -v "$PWD":/src -w /src golang:1.27-trixie go test ./...
```

Тест хранилища PostgreSQL запускается, только если задана тестовая база (таблица `notes` в ней очищается):

```bash
NOTES_TEST_DATABASE_URL='postgres://notes:notes@127.0.0.1:5432/notes?sslmode=disable' go test ./...
```
